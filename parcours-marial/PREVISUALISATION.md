# Prévisualisation du parcours marial (33 jours)

[Ouvrir le lecteur sur téléphone](https://raw.githack.com/benkabor2108-tech/totus-tuus-public/candidate/parcours-marial-33/preview-marial/index.html)

La prévisualisation est hébergée via une passerelle tierce vers la branche `candidate/parcours-marial-33`. Un avertissement de sécurité peut précéder son ouverture. **Ne saisissez aucune donnée personnelle sur la page de la passerelle.**

Les 33 journées affichent les extraits du PDF de référence, une méditation et une prière. L'intégralité du texte extrait est distribuée par plages de pages contiguës, ce qui ne constitue **pas** une validation éditoriale de la méthode de consécration en 33 jours de saint Louis-Marie.

Pour tester : ouvrez le lien dans Chrome Android, affichez les jours 1, 17 et 33, marquez une journée comme lue, puis rechargez. Le mode hors connexion n'est pas garanti depuis cette passerelle. Pour l'essai hors ligne, téléchargez l'archive GitHub Actions et ouvrez les fichiers ensemble depuis un dossier local.

La production `main` V5.10.0 et les données des utilisateurs ne sont pas modifiées. Les tests sur un appareil Android physique restent à effectuer.
