# Test sur téléphone Android — Totus Tuus, parcours marial (candidat)

**Ce dossier est indépendant de l'application publique V5.10.0.** Ne supprimez ni l'application ni ses données.

1. Ouvrez le lien de l'artefact GitHub Actions depuis Chrome et connectez-vous à GitHub si demandé.
2. Téléchargez l'archive « marial-pdf-source-candidat », puis extrayez-la dans l'application Fichiers.
3. Dans le dossier extrait, ouvrez `index.html` dans un navigateur compatible. Les fichiers `parcours-33.js` et `traite-vraie-devotion-fr.pdf` doivent rester à côté du fichier HTML.
4. Sélectionnez les jours 1, 17 et 33. Vérifiez l'affichage des textes et des prières. Marquez un jour comme lu, fermez et rouvrez le lecteur pour vérifier la progression.
5. Activez le mode avion et recommencez la lecture. Vérifiez également l'ouverture du PDF. Certains navigateurs Android bloquent les PDF ou le stockage local ouverts depuis `file://`; dans ce cas, cela ne signifie pas que la version hébergée est défectueuse. Signalez le navigateur utilisé et le comportement observé.

**Limites actuelles :** la lecture sur appareil Android n'a pas été vérifiée en conditions réelles. Le découpage est continu par pages du PDF, sans validation éditoriale des limites de chapitre. Le fichier PDF doit être conservé dans le même dossier pour la lecture locale.

**Confidentialité :** la progression est conservée dans le stockage local du navigateur sous la clé `totus-marial-33-candidate-v1`, distincte des données de la version publique.
